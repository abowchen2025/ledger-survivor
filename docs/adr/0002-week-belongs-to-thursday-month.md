# ADR-0002：一週歸屬於「週四所在的月份」

- 狀態：已採納
- 日期：2026-09-16
- 來源：架構描述 v2.2 第 3.1 節；SRS+FS v1.2 REQ-WEEK-001、REQ-WEEK-002

## 背景

遊戲以週為關卡、以月為賽季。跨月的那一週若切在月底，會產生 1～3 天的殘週；殘週的上限要按比例算、分數要另訂規則，且分數容易被少數幾筆消費放大或稀釋，破壞公平性。

## 決策

- 週一為一週之始（ISO 8601 週）。
- 一週完整歸屬於「該週週四所在的月份」，不切割、不按比例分攤。這是 ISO 8601「週屬於哪一年」的規則套用到月。
- 每月週數 = 該月內週四的個數，必為 4 或 5，由系統自動算出。

## 例子

- 2026/9/28（一）～10/4（日），週四 10/1，整週歸 2026-10 第 1 週。
- 2026/8/31（一）～9/6（日），週四 9/3，整週歸 2026-09 第 1 週。
- 2026/12/28（一）～2027/1/3（日），週四 12/31，整週歸 2026-12，不歸 2027-01。

## 影響

- 後端 `backend/app/services/week_rule.py` 與前端 `frontend/src/lib/week.ts` 各自實作，但共用 `backend/tests/fixtures/week_cases.json` 作唯一真相，任一筆不一致即為 Blocker。
- 所有日期以 Asia/Taipei 本地日曆日存 `DATE` 型別，不用 timestamp（REQ-WEEK-005）。
- 月曆頁跨月週在兩個月份都顯示，並標示「這週算 X 月」。
